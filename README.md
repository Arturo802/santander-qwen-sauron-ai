
# 👁️ Santander Qwen Sauron AI

> "Un anillo para gobernarlos a todos, un modelo para detectarlos a todos..." 

Sistema de ciberseguridad financiera y Prevención de Pérdida de Datos (DLP) que unifica herramientas open-source de **SantanderAI** con el poder local de **Qwen 2.5**. Actúa como el "Ojo de Sauron" vigilando transacciones, detectando fraudes y protegiendo información sensible.

## 🚀 Stack Técnico
* **Python**: IA, lógica de análisis y scripts de integración con Qwen 2.5.
* **Java / Spring Boot**: *(Opcional/Futuro)* Integración con servicios backend.
* **Modelo LLM**: Qwen 2.5 (ejecutado localmente).
